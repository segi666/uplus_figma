## 01 요금제 추천 화면

### 목적
사용자가 요금제를 찾는 방식을 자동 추천과 직접 탐색 중에서 선택한다.

### 라우트
미정 — 화면 01 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "요금제 추천 화면".
- OptionItem × 2 — State=default.
  - "자동 추천": 맞춤 요금제 추천 결과로 이동.
  - "직접 탐색": 요금제 목록 화면으로 이동.

### 상태
- 기본: "요금제를 찾는 방식을 선택해 주세요." 안내와 추천 방식 두 가지를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 서비스 시작.
- 나가는 곳:
  - 자동 추천 → 02 맞춤 요금제 추천 결과.
  - 직접 탐색 → 05 요금제 목록 화면.

## 02 맞춤 요금제 추천 결과

### 목적
자동 추천된 요금제의 요약 정보를 확인하고 상세 페이지로 이동한다.

### 라우트
미정 — 화면 02 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "맞춤 요금제 추천 결과".
- Card/Plan — State=default. 추천 요금제의 요금제명·요금제 구성·월 요금을 표시한다.
- Button — Type=Secondary, Size=xl, State=Default. 문구: "요금제 상세 보기".

### 상태
- 기본: "추천 요금제를 확인해 주세요." 안내와 추천 요금제 카드를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 01 요금제 추천 화면에서 자동 추천 선택.
- 나가는 곳: 요금제 상세 보기 → 03 요금제 상세 페이지.

## 03 요금제 상세 페이지

### 목적
추천 결과 또는 목록에서 선택한 요금제의 구성과 월 요금을 확인한다.

### 라우트
미정 — 화면 03 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "요금제 상세 페이지".
- Card/Plan — State=default. 선택한 요금제의 요금제명·요금제 구성·월 요금을 표시한다.
- 신규: 정보 상자 — "요금제 상세 정보" 영역. 내부 항목은 List/Row를 사용한다.
- List/Row × 2 — Type=default.
  - 제공 내용: 요금제 구성.
  - 이용 요금: 월 요금.
- Button — Type=Secondary, Size=xl, State=Default. 문구: "혜택 및 조건 확인".

### 상태
- 기본: 선택한 요금제의 요약과 상세 정보를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳:
  - 02 맞춤 요금제 추천 결과에서 요금제 상세 보기.
  - 05 요금제 목록 화면에서 요금제 선택.
- 나가는 곳: 혜택 및 조건 확인 → 04 혜택 및 조건 확인.

선택한 요금제의 혜택과 이용 조건을 확인하고 신청 진행 여부를 선택한다.

### 라우트
미정 — 화면 04 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "혜택 및 조건 확인".
- Card/Plan — State=default. 선택한 요금제 정보를 표시한다.
- 신규: 정보 상자 × 2.
  - "제공 혜택": 선택한 요금제의 혜택 안내.
  - "이용 조건": 선택한 요금제의 이용 조건 안내.
- Button × 2 — Type=Secondary, Size=xl, State=Default.
  - "신청하기".
  - "다른 요금제 보기".

### 상태
- 기본: 선택한 요금제, 혜택, 이용 조건과 신청 진행 선택지를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 03 요금제 상세 페이지.
- 나가는 곳:
  - 신청하기 → 06 로그인 / 본인인증.
  - 다른 요금제 보기 → 05 요금제 목록 화면.

### 상태

- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동

- 나가는 곳: 요금제 선택 → 03 요금제 상세 페이지.

## 06 로그인 / 본인인증

### 목적
요금제 신청을 계속하기 위해 로그인 및 본인인증을 진행한다.

### 라우트
미정 — 화면 06 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "로그인 / 본인인증".
- Input × 3 — State=default.
  - 아이디. 자리표시자: "아이디 입력".
  - 비밀번호. 자리표시자: "비밀번호 입력".
  - 본인인증 정보. 자리표시자: "본인인증 정보 입력".
- Button — Type=Secondary, Size=xl, State=Default. 문구: "로그인 / 본인인증".

### 상태
- 기본: 로그인 및 본인인증 안내와 입력 항목을 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 인증 실패 시 07 로그인 / 본인인증 — 오류 안내 메시지로 이동한다.

### 이동
- 들어오는 곳:
  - 04 혜택 및 조건 확인에서 신청하기 선택.
  - 07 로그인 / 본인인증 — 오류 안내 메시지에서 인증 재시도 선택.
- 나가는 곳:
  - 인증 성공 → 08 신청 폼 입력 화면.
  - 인증 실패 → 07 로그인 / 본인인증 — 오류 안내 메시지.

## 07 로그인 / 본인인증 — 오류 안내 메시지

### 목적
인증 실패를 안내하고 입력 정보를 확인한 뒤 인증을 재시도하도록 한다.

### 라우트
미정 — 화면 07 전용 경로.

### 구성 요소
- Header — Type=default. 표시 제목: "로그인 / 본인인증".
- Input × 3 — State=default.
  - 아이디.
  - 비밀번호.
  - 본인인증 정보.
- 신규: 정보 상자 — "오류 안내 메시지" 영역.
  - "인증에 실패했습니다. 입력한 정보를 확인한 후 다시 시도해 주세요."
- Button — Type=Secondary, Size=xl, State=Default. 문구: "인증 재시도".

### 상태
- 기본: 로그인 / 본인인증 입력 항목과 오류 안내를 함께 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 인증 실패 메시지를 표시한다. 제공 화면의 Input은 State=default이며, 오류는 별도 정보 상자에 표시한다.

### 이동
- 들어오는 곳: 06 로그인 / 본인인증에서 인증 실패.
- 나가는 곳: 인증 재시도 → 06 로그인 / 본인인증.

  - 15 실패 안내 및 재시도 안내에서 신청 다시 시도 선택.
- 나가는 곳: 개인정보 입력 → 09 개인정보 입력.

### 상태
- 기본: "입력한 신청 내용을 확인하고 있습니다." 안내를 표시한다.
- 로딩: 신청 처리 상태와 대기 안내를 표시한다. 제공 화면에 없는 스피너나 진행률은 추가하지 않는다.
- 빈: 미정.
- 에러: 신청 실패 결과가 나오면 15 실패 안내 및 재시도 안내로 이동한다.

### 이동
- 들어오는 곳: 12 입력 내용 확인에서 최종 제출.
- 나가는 곳:
  - 신청 성공 → 14 신청 완료 화면.
  - 신청 실패 → 15 실패 안내 및 재시도 안내.

## 14 신청 완료 화면

### 목적
신청 성공을 알리고 신청한 요금제의 구독 내역 확인으로 연결한다.

### 라우트
미정 — 화면 14 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "신청 완료 화면".
- 신규: 정보 상자.
  - "신청이 완료되었습니다".
  - "선택한 요금제의 구독 내역을 확인해 주세요."
- Card/Plan — State=default. 신청한 요금제 정보를 표시한다.
- Button — Type=Secondary, Size=xl, State=Default. 문구: "구독 내역 확인".

### 상태
- 기본: 신청 완료 안내와 선택한 요금제 정보를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 13 신청 처리 중...에서 신청 성공.
- 나가는 곳: 구독 내역 확인 → 16 구독 내역 확인.

## 15 실패 안내 및 재시도 안내

### 목적
신청 실패를 안내하고 신청 폼으로 돌아가 다시 시도하도록 한다.

### 라우트
미정 — 화면 15 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "실패 안내 및 재시도 안내".
- 신규: 정보 상자.
  - "신청에 실패했습니다".
  - "신청 폼으로 돌아가 입력한 정보를 확인한 후 다시 시도해 주세요."
- Card/Plan — State=default. 선택한 요금제 정보를 표시한다.
- Button — Type=Secondary, Size=xl, State=Default. 문구: "신청 다시 시도".

### 상태
- 기본: 신청 실패 안내와 선택한 요금제 정보를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 신청 실패 상태를 표시한다. 구체적인 실패 원인이나 오류 코드는 제공 자료에 없다.

### 이동
- 들어오는 곳: 13 신청 처리 중...에서 신청 실패.
- 나가는 곳: 신청 다시 시도 → 08 신청 폼 입력 화면.

## 16 구독 내역 확인

### 목적
신청 완료된 요금제와 구독 정보를 확인하고 서비스 이용을 시작한다.

### 라우트
미정 — 화면 16 전용 경로.

### 구성 요소
- Header — Type=default. 제목: "구독 내역 확인".
- Card/Plan — State=default. 신청한 요금제의 요금제명·요금제 구성·월 요금을 표시한다.
- 신규: 정보 상자 — "구독 정보" 영역. 내부 항목은 List/Row를 사용한다.
- List/Row × 3 — Type=default.
  - 신청 상태: 신청 완료.
  - 개인정보: 입력한 정보.
  - 결제 수단: 선택한 결제 수단.
- Button — Type=Secondary, Size=xl, State=Default. 문구: "서비스 이용 시작".

### 상태
- 기본: "신청한 요금제의 구독 내역입니다." 안내와 요금제·구독 정보를 표시한다.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 14 신청 완료 화면에서 구독 내역 확인 선택.
- 나가는 곳: 서비스 이용 시작 → 흐름 종료. 이후 화면이나 이동 경로는 제공 자료에 없다.
