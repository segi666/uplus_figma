# Design.md

로컬 베리어블, 텍스트 스타일, Components 영역의 컴포넌트와 390×844 모바일 화면을 기준으로 작성했다.

- 변수 값은 각 컬렉션의 `Default` 모드를 기준으로 한다.
- 치수 단위는 별도 표시가 없으면 px이다.
- 기존 문서 예시보다 현재 변수·스타일·컴포넌트 정의를 우선한다.
- 확인된 설정과 구현 시 적용할 규칙을 구분한다. 적용 위치가 확인되지 않은 토큰은 별도로 표시한다.

## 1. 색 팔레트

색상은 `primitive → semantic` 별칭 구조를 사용한다. 화면에는 색상값을 직접 지정하기보다 역할에 맞는 semantic 토큰을 적용한다.

### 1.6 브랜드·효과

| Semantic 토큰 | 값 | 참조 primitive | 쓰는 곳 |
|---|---|---|---|
| `brand/primary` | `#FF2E98` | `pink/500` | Logo의 브랜드 도형 |
| `effect/shadow-subtle` | `#0000000D` | 직접 지정 | 검정 약 5%의 그림자 색상용. Components 내 적용은 확인되지 않음 |

`effect/shadow-subtle`은 색상 변수다. 그림자의 위치·blur·spread까지 정의한 효과 스타일은 아니다. 로컬 효과 스타일은 등록되어 있지 않다.

### 1.7 적용 규칙

- 브랜드 표현은 `brand/primary`, 주요 액션 채움은 `fill/primary`로 구분한다.
- 텍스트 강조 색상 `#FF2E98`과 주요 버튼 채움 `#E6007E`를 혼동하지 않는다.
- 입력 상태는 `border/default → border/focus / border/error`로 표현한다.
- 선택 상태가 모두 분홍색인 것은 아니다. Card/Plan과 OptionItem은 `border/medium`, FilterChip은 `fill/secondary`를 사용한다.
- 투명도가 있는 토큰은 알파 값을 유지한다.
- 현재 비활성 버튼의 레이블은 `text/on-dark`다. `text/on-disabled`가 적용된 것으로 해석하지 않는다.

## 2. 타이포 스케일

### 2.1 기본 설정

- 서체: `Noto Sans KR`
- 서체 변수: `font-family/family-font`
- 모든 로컬 텍스트 스타일의 자간: `0%`
- 모든 로컬 텍스트 스타일의 문단 간격: `0`
- 아래 크기·줄높이·굵기는 개별 텍스트의 오버라이드가 아닌 텍스트 스타일 정의를 기준으로 한다.

### 2.3 서체 견본 스타일

다음 스타일도 등록되어 있으나, 제품 UI의 추가 제목 단계가 아니라 굵기 비교용 견본이다.

| 텍스트 스타일 | 크기 / 줄높이 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `specimen/weight-medium` | 32 / 44 | Medium 500 | 서체 굵기 비교 |
| `specimen/weight-semibold` | 32 / 44 | SemiBold 600 | 서체 굵기 비교 |

### 2.4 적용 규칙과 현재 예외

- 텍스트에는 역할에 맞는 등록 스타일을 적용한다.
- 가격 카드의 핵심 금액과 카드 목록의 금액은 서로 다른 위계를 사용한다. 각각 `heading/h2`, `subtitle/bold`를 기준으로 한다.
- OptionItem은 선택 시 제목이 `body/strong`에서 `subtitle/bold`로 바뀐다. 색상뿐 아니라 크기·굵기·높이도 달라진다.
- 현재 일부 컴포넌트에는 SemiBold 스타일을 연결한 상태에서 실제 굵기를 Regular 400으로 바꾼 오버라이드가 있다.
  - Input 값, 다수 버튼 레이블, default Header 제목
  - List/Row 값, 기본 OptionItem 제목, 선택된 FilterChip
  - benefit·package Chip 레이블
- 따라서 스타일 정의의 600과 현재 일부 도형의 실제 400을 같은 값으로 취급하지 않는다. 위 표는 등록된 스타일 스케일이며, 기존 화면을 그대로 재현할 때는 해당 오버라이드를 별도로 확인한다.

### 3.3 390×844 모바일 구조

| 항목 | 기준 |
|---|---|
| 화면 | 390 × 844 |
| Header | 390 × 56 |
| Header 좌우 padding | 16 |
| 기본 콘텐츠 좌우 padding | 16 |
| 기본 콘텐츠 폭 | 358 = 390 − 16 × 2 |
| 여유 있는 본문 좌우 padding | 24 |
| 해당 본문 콘텐츠 폭 | 342 = 390 − 24 × 2 |
| 일반 본문 그룹 간격 | 16 또는 24 |
| 그룹 내부 간격 | 주로 8 또는 12 |
| 전체 폭 컴포넌트 원본 기준 폭 | 주로 358 |
| 기본 주요 버튼 높이 | xl 52 |
| 기본 하단 안전 여백 | BottomCTA 기준 32 |

현재 화면에 16과 24의 좌우 여백이 함께 존재한다. 모든 화면을 16으로 단정하지 않는다.

확인된 화면별 예시는 다음과 같다.

| 화면 유형 | 본문 좌우 padding | 주요 구성 간격 |
|---|---:|---:|
| 요금제 목록 | 24 | 본문 그룹 16, 필터·카드 사이 8 |
| 요금제 상세 | 24 | 주요 그룹 24, 그룹 내부 12 |
| 구독 신청 | 16 | 주요 그룹 16 |
| 신청 완료 | 16 | 주요 그룹 24 |

- 본문은 세로 Auto Layout을 사용한다.
- 카드·입력·목록 행은 부모 콘텐츠 폭에 맞춰 Fill로 배치한다. 원본 폭 358을 모든 화면에서 고정하지 않는다.
- 별도의 OS 상태바 높이는 화면에 정의되어 있지 않다. Header는 화면 상단 y=0에서 시작한다.

### 3.4 하단 액션 영역

#### 공통 BottomCTA

| Layout | 전체 크기 | 내부 배치 |
|---|---|---|
| `single` | 390 × 97 | 358 × 52 주요 버튼 하나 |
| `double` | 390 × 97 | 보조·주요 버튼 가로 배치, 간격 8 |
| `price` | 390 × 139 | 금액 행 + 간격 12 + 358 × 52 주요 버튼 |

- `single`, `double`: 위 12, 좌우 16, 아래 32 padding.
- `price`: 위 16, 좌우 16, 아래 32 padding.
- 상단 구분선이 포함되므로 실측 높이는 각각 97, 139다.
- `double`의 버튼 폭은 동일하지 않다. 원본에서 보조 약 133, 주요 약 217이다.

#### 화면별 별도 하단 구성

일부 화면은 BottomCTA가 아니라 Button 두 개를 세로로 쌓은 별도 영역을 사용한다.

| 화면 유형 | 영역 높이 | 좌우 padding | 버튼 사이 | 아래 padding |
|---|---:|---:|---:|---:|
| 요금제 상세 | 160 | 24 | 8 | 32 |
| 구독 신청 | 152 | 24 | 8 | 24 |

이 구성의 버튼 폭은 342, 높이는 각각 52다. BottomCTA의 `double`과 혼동하지 않는다.

### 3.5 구현 시 레이아웃 규칙

- Header와 하단 액션 영역을 고정한다면 본문에 남는 높이를 기준으로 스크롤 영역을 만든다.
  - 기본 BottomCTA: 844 − 56 − 97 = 691
  - 금액형 BottomCTA: 844 − 56 − 139 = 649
- 위 가용 높이는 구현 계산값이다. 현재 예시 화면에 스크롤 동작이 설정되어 있다는 의미는 아니다.
- 실제 확인한 예시 화면의 스크롤 설정은 `NONE`이다. 긴 목록의 스크롤은 별도 구현이 필요하다.
- 카드·입력의 높이는 텍스트 줄 수, 메시지, 선택 상태에 따라 늘어날 수 있도록 한다.
- 시각적인 아이콘 크기와 실제 조작 영역은 분리해서 설계한다.

## 4. 컴포넌트 용법

속성 이름은 인스턴스에 표시되는 이름을 기준으로 하며 내부 식별자 접미사는 생략했다.

- Variant: 정의된 변형 전환
- Text: 공개된 텍스트 교체 속성
- Boolean: 연결된 하위 요소의 표시 여부

### 4.1 Input

- 변형: `State = default | focus | filled | caution | disabled`
- 기본 변형: `default`
- 공개 속성:
  - `State`: Variant
  - `errorMessage`: Boolean, 기본 false
- 크기:
  - 기본 field: 358 × 58
  - caution 전체: 358 × 91
- 형태: 둥근 박스가 아니라 하단 1.5 두께의 밑줄형 입력이다.

| State | 사용 조건 | 표현 |
|---|---|---|
| `default` | 입력 전 | 기본 밑줄 + placeholder |
| `focus` | 입력 중 | focus 밑줄 |
| `filled` | 값 입력 후 | 기본 밑줄 + 본문 색상 값 |
| `caution` | 검증 실패 | error 밑줄 + 오류 아이콘·메시지 |
| `disabled` | 입력 불가 | 옅은 배경 + 비활성 텍스트 |

사용 규칙:
- 오류 표시에는 `caution`을 사용한다. 별도의 `error` 변형은 없다.
- 오류 메시지는 field 아래 12 간격으로 배치된다.
- 입력값·placeholder·오류 문구를 교체하는 공개 Text 속성은 없다. 현재는 내부 텍스트 오버라이드가 필요하다.
- `errorMessage`는 default·focus·filled·disabled의 메시지 가시성에 연결되어 있다.
- caution의 메시지는 기본 표시 상태이며 `errorMessage`와 연결되어 있지 않다. 이 Boolean으로 caution 메시지를 숨길 수 있다고 가정하지 않는다.

### 4.2 Checkbox

- 변형: `State = default | active`
- 기본 변형: `default`
- 공개 속성: `State`만 제공
- 크기: 24 × 24

사용 규칙:
- 동의 여부 등 독립적으로 켜고 끄는 선택에 사용한다.
- 단일 선택 카드에는 OptionItem을 사용한다.
- 레이블을 포함하지 않으므로 관련 텍스트를 외부에서 함께 배치한다.
- 별도의 disabled·error 변형은 정의되어 있지 않다.

### 4.3 Button

- 변형:
  - `Type = Primary | Secondary`
  - `Size = sm | lg | xl`
  - `State = Default | Hover | Disabled`
- 기본 조합: `Primary / xl / Default`
- 공개 Text 속성: `Label`
- 모서리: `radius/8`
- 좌우 padding: 24

| Size | Primary 높이 | Secondary 높이 |
|---|---:|---:|
| `sm` | 40 | Default·Hover 42, Disabled 40 |
| `lg` | 48 | 48 |
| `xl` | 52 | 52 |

사용 규칙:
- Primary는 핵심 액션, Secondary는 보조 액션에 사용한다.
- 하단 주요 액션은 주로 `xl`, 카드 내부 액션은 `sm`을 사용한다.
- 너비는 콘텐츠에 맞추거나 부모 레이아웃에 맞춰 늘린다.
- 사용 불가 상태는 `Disabled`로 표현하며 실제 동작 차단도 함께 구현한다.
- `Pressed`, `Loading` 변형은 정의되어 있지 않다.
- Secondary sm의 테두리 포함 실측 높이는 42다. 모든 sm 버튼이 40이라고 단정하지 않는다.
- Primary의 Default와 Hover는 현재 동일한 색상값을 사용한다.

### 4.4 BottomCTA

- 변형: `Layout = single | double | price`
- 기본 변형: `single`
- 공개 Text 속성:
  - `Amount`
  - `AmountLabel`
- 크기: single·double 390 × 97, price 390 × 139

사용 규칙:
- `single`: 핵심 액션 하나.
- `double`: 보조 액션 왼쪽, 핵심 액션 오른쪽의 가로 배치.
- `price`: 금액 요약과 핵심 액션을 함께 보여주는 결정 화면.
- `Amount`, `AmountLabel`은 price 구성에서 사용한다.
- 버튼 문구는 상위 BottomCTA가 아니라 내부 Button의 `Label` 속성으로 변경한다.
- 하단 32 여백과 상단 구분선을 유지한다.
- 세로 버튼 두 개가 필요한 화면은 현재 별도의 화면 레이아웃으로 구성되어 있다.

### 4.5 Header

- 변형: `Type = default | root`
- 기본 변형: `default`
- 공개 Text 속성: `Title`
- 크기: 390 × 56
- 좌우 padding: 16

사용 규칙:
- `default`: 뒤로가기 아이콘 + 가운데 제목. 반대편 spacer로 중앙 정렬을 유지한다.
- `root`: 뒤로가기 없이 왼쪽 제목 + 오른쪽 Logo.
- default 제목은 `subtitle/default`, root 제목은 `heading/h4`를 기준으로 한다.
- 화면당 하나를 사용한다.

### 4.6 StepProgress

- 변형: `Step = 1 | 2 | 3`
- 기본 변형: `1`
- 공개 속성: `Step`만 제공
- 크기: 358 × 30
- track 높이: 4
- 레이블과 track 사이: 8

| Step | 레이블 | 원본 bar 폭 |
|---|---|---:|
| `1` | STEP 1 / 3 | 119 |
| `2` | STEP 2 / 3 | 239 |
| `3` | STEP 3 / 3 | 358 |

사용 규칙:
- 3단계 흐름에서 현재 위치를 표시한다.
- 다른 콘텐츠 폭에서는 진행 비율을 약 1/3, 2/3, 3/3으로 유지한다.
- 임의의 총 단계 수를 설정하는 속성은 없다.

### 4.7 OptionItem

- 변형: `State = default | selected`
- 기본 변형: `default`
- 공개 Text 속성: `Title`, `Desc`
- 원본 크기: default 358 × 83, selected 358 × 86
- padding: 위아래 16, 좌우 20
- 모서리: `radius/12`

사용 규칙:
- 설명을 포함한 단일 선택 항목에 사용한다.
- 같은 그룹에서 selected는 한 번에 하나다.
- 선택 시 `bg/default`, `border/medium` 1.5, 라디오 선택 표시를 사용한다.
- 선택 시 제목 스타일도 커지므로 높이 변화가 발생한다.
- 기본 항목과 선택 항목의 높이를 강제로 동일하게 고정하지 않는다.

### 4.8 FilterChip

- 변형: `State = default | selected`
- 기본 변형: `default`
- 공개 Text 속성: `Label`
- 높이: 40
- 좌우 padding: 16
- 모서리: `radius/full`
- 너비: 문구에 따라 증가

사용 규칙:
- 조건·분류·정렬의 빠른 선택에 사용한다.
- 현재 컴포넌트 설명상 같은 그룹에서 selected는 한 번에 하나다.
- 기본은 흰 표면과 기본 테두리, 선택은 어두운 채움과 밝은 텍스트다.
- 상태를 나타내는 비조작형 Chip·Tag와 구분한다.

### 4.9 List/Row

- 변형: `Type = default | check`
- 기본 변형: `default`
- 공개 Text 속성: `Label`, `Value`
- 원본 크기: 358 × 46
- padding: 위아래 12, 좌우 4
- 내부 간격: 12

사용 규칙:
- `default`: 라벨 왼쪽, 값 오른쪽의 정보 행.
- `check`: 혜택 행. 왼쪽에 6 크기의 강조 점을 추가하고 값을 accent 색상으로 표시한다.
- `check`는 체크박스가 아니며, 실제 체크 아이콘 대신 점 표시를 사용한다.
- 같은 목록의 라벨과 값 정렬을 일관되게 유지한다.

### 4.10 Card/Price

- Components 영역에는 외부 컴포넌트의 인스턴스로 배치되어 있다.
- 변형·공개 속성: 없음
- 원본 크기: 358 × 124
- padding: 20
- 내부 간격: 4
- 모서리: `radius/12`
- 배경: `bg/default`

사용 규칙:
- 금액 라벨, 핵심 금액, 할인율, 정가·보조 정보를 요약한다.
- 핵심 금액은 `heading/h2`, 할인율은 `subtitle/bold`, 보조 정보는 `caption/medium`을 사용한다.
- 공개 Text 속성이 없으므로 내용 교체는 현재 인스턴스의 텍스트 오버라이드로 처리한다.
- 콘텐츠 폭에 맞춰 늘리거나 줄이며, 실제 상세 화면에서는 폭 342로 사용된다.

### 4.11 Card/Plan

- 변형: `State = default | selected`
- 기본 변형: `default`
- 공개 Text 속성:
  - `Name`
  - `Desc`
  - `Discount`
  - `Price`
  - `Original`
- 공개 Boolean 속성:
  - `Badge`, 기본 true
  - `Promo`, 기본 true
  - `Sale`, 기본 true
- 원본 크기: default 358 × 223, selected 358 × 224
- padding: 20
- 기본 내부 간격: 8
- 모서리: `radius/16`

사용 규칙:
- 요금제 이름·설명·금액·부가 표시·상세 액션을 묶는 카드다.
- default는 `border/default` 1, selected는 `border/medium` 1.5를 사용한다.
- `Sale`은 할인율과 정가의 표시 여부를 함께 제어한다.
- `Promo`는 프로모션 Chip의 표시 여부를 제어한다.
- 카드 내부 버튼 문구는 내부 Button의 `Label` 속성으로 변경한다.
- 텍스트 줄 수와 부가 표시 여부에 따라 높이가 달라질 수 있으므로 Hug 높이를 유지한다.

현재 속성 연결 주의:
- `Badge`는 공개 속성으로 정의되어 있지만 두 변형 모두 배지의 가시성에 연결되어 있지 않다.
- 따라서 `Badge=false`만으로 배지가 숨겨진다고 가정하지 않는다. 배지 숨김을 재사용 가능한 동작으로 쓰려면 속성 연결을 보완해야 한다.

### 4.12 Chip

- 변형: `Type = benefit | package | sale`
- 기본 변형: `sale`
- 공개 Text·Boolean 속성: 없음

| Type | 높이 | 모서리 | 표현 |
|---|---:|---:|---|
| `benefit` | 20 | 4 | 옅은 중립 배경, 작은 혜택 정보 |
| `package` | 20 | 4 | 어두운 배경, 밝은 작은 레이블 |
| `sale` | 24 | 6 | 옅은 강조 배경, 강조 레이블 |

사용 규칙:
- 짧은 혜택·패키지·할인 정보를 보조적으로 표시한다.
- 선택 컨트롤이 아니므로 필터에는 FilterChip을 사용한다.
- 레이블 교체용 공개 속성이 없어 내부 텍스트 오버라이드가 필요하다.
- benefit·package는 `caption/mini`, sale은 `caption/bold`를 기준으로 한다.

### 4.13 Tag

- 변형·공개 속성: 없음
- 기본 문구 기준 크기: 48 × 26
- padding: 위아래 4, 좌우 12
- 모서리: `radius/999`
- 텍스트 스타일: `caption/bold`

사용 규칙:
- 추천 등 짧은 분류·강조 표시에 사용한다.
- 너비는 문구에 따라 달라진다.
- 현재 채움은 `border/subtle`, 텍스트는 `text/secondary`다.
- 선택이나 실행 기능이 필요한 경우 FilterChip 또는 Button을 사용한다.
- 공개 Text 속성은 없다.

### 4.14 icon/arrowLeft

- 변형·공개 속성: 없음
- 크기: 24 × 24

사용 규칙:
- default Header의 뒤로가기 표시에 사용한다.
- 방향과 비율을 유지한다.
- 실제 조작 영역은 상위 컨테이너에서 별도로 확보한다.

### 4.15 icon/check

- 변형·공개 속성: 없음
- 크기: 24 × 24

사용 규칙:
- 완료·포함 상태를 보조한다.
- Checkbox와 같은 선택 컨트롤로 사용하지 않는다.
- 배경에 따라 적절한 대비를 유지한다. 완료 마크 내부에서는 밝은 체크로 사용된다.

### 4.16 icon/doneMark

- 변형·공개 속성: 없음
- 크기: 64 × 64
- 형태: `fill/primary` 원형 배경 + 내부 체크

사용 규칙:
- 신청 완료 등 결과 화면의 대표 상태 표시에 사용한다.
- 일반 목록의 작은 완료 표시와 구분한다.
- 크기를 축소해 Checkbox 대용으로 사용하지 않는다.

### 4.17 Logo

- 변형·공개 속성: 없음
- 크기: 32 × 24
- 브랜드 도형 색상: `brand/primary`

사용 규칙:
- root Header 등 브랜드 식별이 필요한 위치에 사용한다.
- 원본 비율·도형을 유지한다.
- 일반 아이콘의 상태 색상으로 대체하지 않는다.

### 4.18 공통 사용 규칙

- 공개된 Variant·Text·Boolean 속성이 있으면 해당 속성을 우선 사용한다.
- 공개 속성이 없는 내용만 필요한 범위에서 인스턴스 오버라이드로 교체한다.
- 동일한 역할에는 동일한 컴포넌트와 변형을 재사용한다.
- 정의된 상태 이름과 실제 서비스 상태를 명시적으로 연결한다.
- 선택 상태를 일괄적으로 분홍색으로 바꾸지 않는다. 각 컴포넌트의 원본 상태 표현을 유지한다.
- 컴포넌트의 기준 폭과 화면의 실제 콘텐츠 폭을 구분한다.
- 공개 속성의 존재만으로 동작을 보장하지 않는다. 특히 Input의 caution 메시지와 Card/Plan의 Badge 연결 예외를 반영한다.
