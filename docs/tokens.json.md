# 디자인 토큰 설명 (기획자용)

> 원본: [tokens.json.txt](tokens.json.txt)
> 원본은 JSON 형식이라 주석을 넣을 수 없어서, 같은 내용을 이 문서에 설명으로 정리했습니다. 원본 파일은 바꾸지 않았습니다.

[기획] 이 파일은 특정 화면이 아니라 **모든 화면이 함께 쓰는 디자인 규칙표(디자인 토큰)**입니다. 색상, 글자 크기, 여백, 모서리 둥글기를 이름으로 정해 두고, 화면을 만들 때 이 이름을 가져다 씁니다.

[기획] 규칙표는 다섯 묶음입니다.

| 묶음 | 원본 줄 | 내용 |
|---|---|---|
| 기본 색상표 (primitive) | 2–20 | 회색, 분홍, 빨강 등 실제 색상 목록 |
| 쓰임별 색상 (semantic) | 21–212 | "본문 글자", "오류 테두리"처럼 쓰임새마다 정한 색 |
| 글자 (typography) | 213–225 | 글꼴, 제목과 본문 글자 크기 |
| 여백 (spacing) | 226–245 | 요소 사이 간격 |
| 모서리 둥글기 (radius) | 246–262 | 버튼과 카드 모서리를 둥글게 만드는 정도 |

---

## 1. 기본 색상표 (primitive) — 원본 2–20줄

[기획] 화면에서 실제로 쓰는 색상을 모아 둔 팔레트입니다. 화면은 보통 이 색을 직접 쓰지 않고, 아래 "쓰임별 색상"을 거쳐서 씁니다.

[기획] 이름 뒤 숫자가 클수록 진한 색입니다. 예를 들어 `gray/900`은 거의 검정이고 `gray/0`은 흰색입니다.

| 이름 | 색상 | 설명 |
|---|---|---|
| gray/950 | #000000 | 순수 검정 |
| gray/900 | #181A1B | 거의 검정. 본문 글자에 쓰는 색 |
| gray/800 | #2D2D2D | 진한 회색. 어두운 배경에 쓰는 색 |
| gray/600 | #66707A | 중간 회색. 보조 글자와 아이콘에 쓰는 색 |
| gray/500 | #878787 | 연한 중간 회색 |
| gray/400 | #B7BDC4 | 연회색. 입력창 안내 문구에 쓰는 색 |
| gray/300 | #D9DCDF | 테두리용 연회색 |
| gray/200 | #EFF1F3 | 아주 연한 회색 |
| gray/100 | #F7F7F7 | 화면 바탕용 회색 |
| gray/0 | #FFFFFF | 흰색 |
| pink/600 | #E6007E | 진한 분홍. 주요 버튼 색 |
| pink/500 | #FF2E98 | 분홍. 강조 글자와 브랜드 색 |
| pink/50 | #FFF5FA | 아주 연한 분홍 배경 |
| pink/25 | #FFF8F5 | 가장 연한 분홍 배경 |
| red/500 | #E30036 | 빨강. 오류 표시 |
| red/50 | #FFF0F3 | 아주 연한 빨강 배경 |
| black/10 | #000000, 투명도 10% | 반투명 검정. 구분선 |

[기획] (확인 필요) `pink/25`(16줄)는 기본 색상표에만 있고, 쓰임별 색상에서는 쓰지 않습니다. 실제로 어느 화면에서 쓰는지 확인이 필요합니다.

## 2. 쓰임별 색상 (semantic) — 원본 21–212줄

[기획] "어디에 쓰는 색인지"를 이름으로 정한 목록입니다. 예를 들어 `text/error`는 "오류 메시지 글자 색"입니다. 나중에 오류 색을 바꾸고 싶으면 이 한 곳만 바꾸면 모든 화면에 반영됩니다.

[기획] 각 항목의 `primitive`는 위 기본 색상표에서 어떤 색을 가져왔는지를 뜻합니다.

| 이름 | 원본 줄 | 색상 | 화면에서 쓰는 곳 |
|---|---|---|---|
| text/primary | 37 | gray/900 | 제목과 본문 등 기본 글자 |
| text/secondary | 42 | gray/600 | 설명 문구 같은 보조 글자 |
| text/tertiary | 47 | gray/500 | 날짜, 부가 정보처럼 덜 중요한 글자 |
| text/accent | 27 | pink/500 | 강조하고 싶은 글자 (예: 금액, 링크) |

| text/error | 57 | red/500 | 오류 안내 문구 |
| text/placeholder | 62 | gray/400 | 입력창에 아무것도 입력하지 않았을 때 보이는 안내 문구 |
| text/on-disabled | 67 | gray/600 | 누를 수 없는 상태인 버튼의 글자 |

[기획] (확인 필요) `text/on-disabled`(67줄)는 보조 글자(`text/secondary`)와 같은 색입니다. 비활성 버튼 글자가 일반 보조 글자와 구분되지 않아도 되는지 확인이 필요합니다.

### 2-3. 테두리와 구분선 (border/…)

| 이름 | 원본 줄 | 색상 | 화면에서 쓰는 곳 |
|---|---|---|---|
| border/default | 102 | gray/300 | 입력창, 카드의 기본 테두리 |
| border/subtle | 107 | gray/200 | 아주 옅은 테두리 |
| border/medium | 172 | gray/600 | 조금 더 또렷한 테두리 |
| border/strong | 112 | gray/900 | 가장 진한 테두리 (예: 선택된 항목) |

| border/focus | 122 | pink/500 | 입력창을 눌러 입력 중일 때 테두리 |
| border/error | 127 | red/500 | 입력값이 잘못됐을 때 입력창 테두리 |

[기획] 입력창은 상태에 따라 테두리 색이 바뀝니다. 평소에는 회색(`border/default`), 입력 중에는 분홍(`border/focus`), 오류가 있으면 빨강(`border/error`)입니다.

### 2-4. 버튼과 채우기 색 (fill/…)

|---|---|---|---|
| fill/primary | 132 | pink/600 | 가장 중요한 버튼 (예: 다음, 확인, 신청) |
| fill/primary-hover | 157 | pink/600 | 주요 버튼에 마우스를 올렸을 때 |
| fill/accent | 22 | pink/600 | 강조 요소 채우기 |
| fill/secondary | 137 | gray/900 | 두 번째로 중요한 버튼 (검정 버튼) |
| fill/tertiary | 142 | gray/200 | 덜 중요한 버튼 (연회색 버튼) |
| fill/disabled | 147 | gray/300 | 누를 수 없는 상태의 버튼 |
| fill/disabled-strong | 152 | gray/400 | 누를 수 없는 상태를 더 진하게 보여줄 때 |

[기획] 버튼은 중요도에 따라 분홍 → 검정 → 연회색 순으로 씁니다. 조건이 맞지 않아 누를 수 없을 때는 회색(`fill/disabled`)으로 바뀝니다.

[기획] (확인 필요) `fill/accent`(22줄)와 `fill/primary`(132줄)는 같은 색입니다. 둘을 나눠 둔 이유가 있는지 확인이 필요합니다.

## 3. 글자 (typography) — 원본 213–225줄

[기획] 모든 화면은 **Noto Sans KR** 글꼴을 씁니다. 글자 크기는 아래 단계 중에서 골라 씁니다. (단위: px)

| 이름 | 크기 | 화면에서 쓰는 곳 |
|---|---|---|
| heading-h1 | 32 | 화면에서 가장 큰 제목 |
| heading-h2 | 28 | 큰 제목 |
| heading-h3 | 24 | 중간 제목 |
| heading-h4 | 20 | 작은 제목 |
| subtitle | 18 | 소제목 |
| body | 16 | 기본 본문 |
| body-small | 14 | 작은 본문 |
| caption | 13 | 설명 문구, 안내 문구 |
| font-size/12 | 12 | 아주 작은 글자 |
| caption-mini | 10 | 가장 작은 글자 (예: 배지, 라벨) |

[기획] (확인 필요) `font-size/12`(224줄)만 쓰임새 이름 대신 숫자로 되어 있습니다. 어디에 쓰는 크기인지 확인이 필요합니다.

[기획] (확인 필요) 글자 굵기와 줄 간격은 정해져 있지 않습니다. 다른 문서에서 관리하는지 확인이 필요합니다.

## 4. 여백 (spacing) — 원본 226–245줄

[기획] 요소 사이 간격을 정한 값입니다. 이름의 숫자가 곧 간격 크기(px)입니다. 예를 들어 `spacing/16`은 16px 간격입니다.

[기획] 쓸 수 있는 값은 작은 순서로 다음과 같습니다.
0, 2, 4, 6, 8, 10, 12, 16, 20, 24, 28, 32, 40, 48, 56, 60, 64, 80

[기획] (확인 필요) 대부분 4의 배수인데, 2·6·10 같은 값이 섞여 있습니다. 4 단위 규칙의 예외로 허용한 값인지 확인이 필요합니다.

## 5. 모서리 둥글기 (radius) — 원본 246–262줄

[기획] 버튼, 카드, 입력창 모서리를 얼마나 둥글게 할지 정한 값입니다. 숫자가 클수록 더 둥글어집니다. (단위: px)

[기획] 쓸 수 있는 값은 작은 순서로 다음과 같습니다.
0(각진 모서리), 2, 4, 5, 6, 8, 10, 12, 16, 20, 24, 32, 40, 999, full(9999)

[기획] `radius/full`과 `radius/999`는 양 끝을 완전히 둥글게 만드는 값입니다. 알약 모양 버튼이나 동그란 프로필 사진에 씁니다.

[기획] (확인 필요) `radius/999`(259줄)와 `radius/full`(254줄)은 화면에서 똑같이 보입니다. 하나로 통일할지 확인이 필요합니다.

[기획] (확인 필요) 5, 6, 10처럼 규칙에서 벗어난 값이 있습니다. 실제로 쓰는 화면이 있는지 확인이 필요합니다.
